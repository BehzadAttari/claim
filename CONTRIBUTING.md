# Contributing to got-a.page

Welcome - whether you're claiming your first page or improving the whole
neighbourhood. This is a friendly repo for first-time open-source
contributors, and maintainers are happy to help.

## Claim a page (most people want this)

1. **Fork** this repo with the button at the top right.
2. In your fork, open the `pages/` folder and click **Add file - Create new
   file**.
3. Name it `yourname.json` - lowercase letters, numbers and hyphens only,
   2-40 characters. The filename becomes `yourname.got-a.page`.
4. Paste a starter from the [README](README.md) and make it yours. Even
   easier: use the **guided claim form** at
   [got-a.page/claim](https://got-a.page/claim) - it writes the JSON for you.
5. Scroll down, choose **Create a new branch for this commit and start a pull
   request**, and propose the change.
6. Our checker comments within seconds. If it asks for a fix, edit the file on
   the same branch and the pull request updates itself.
7. A maintainer merges. You've got a page.

### The fine print that keeps things fair

- `owner.github` must be your own GitHub username, and new pages must come
  from that account.
- Only you (or a maintainer) can edit or delete your page later.
- Two pages per account while we grow. Need more for a community? Open an
  issue and let's talk.
- Everything here is public, forever. Don't put anything private in your file.

## Improve the project

- **Ideas and bugs**: open an issue. `good first issue` and `help wanted`
  labels mark friendly starting points.
- **Code**: scripts are TypeScript. Run `npm ci && npm test` before your PR.
- **Docs and translations**: just as welcome as code.
- **Design**: themes and page templates have their own guide in the renderer
  repo once Phase 2 opens them up.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md). In short: be warm,
assume good intent, celebrate beginners.
